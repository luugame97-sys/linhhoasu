Thông báo chạy ngang trong game

Có thể làm bằng UI native

Client đã có MarqueeWin, một dòng chạy phải → trái, tốc độ 90, gần đầu màn hình.

Luồng có sẵn

WSServer.broadcast → tag 1601 → ChatModel.doWorldChatAdd → system notice → MarqueeModel.addMarquee → MarqueeWin

Khoảng trống

Hàm pushSystemBroadcast hiện dùng msgType=14, nên chủ yếu vào chat, chưa kích hoạt marquee. Config cũng chưa có template chung {0} cho nội dung tùy ý.

Phương án chuẩn

  1. Thêm MessageConfig native riêng: {0}, notice=1.
  2. Đồng bộ config client/server.
  3. Thêm API HMAC broadcast marquee, giới hạn 200 ký tự và rate-limit.
  4. Broadcast tag 1601 với noticeId riêng.
  5. Thêm form WebGM: nội dung, số lượt, khoảng cách, preview/confirm.

Trạng thái

Chỉ audit; chưa phát test, chưa sửa hoặc restart production.
